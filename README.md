# General Health Prediction

Machine Learning based General Health Prediction using Logistic Regression and SVM.

## Models
- Logistic Regression
- Support Vector Machine (SVM)

## Features
- 80:20 train-test split
- Accuracy evaluation
- Classification report
- Confusion matrix
- Accuracy comparison
- RandomizedSearchCV hyperparameter tuning
- Single-person health prediction

## Dataset
CVD_cleaned.csv
